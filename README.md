#how the other person sees the color.

## Description

**version 1.0**

This program allows the user to explore how colors appear under different types of color vision. The user can choose between original color vision, Protanopia, Deuteranopia, and Tritanopia to compare how different colors may appear.

To run the program, give the following commands:
